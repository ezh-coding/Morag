# מורג 108 — עדכון

## ⚠️ חשוב לפני שמעלים
העתיקו את קובץ הלוגו שלכם `morag_logo.png` לתוך התיקייה הזו (index.html מצפה לקובץ בשם הזה, לצידו).

## מה חדש בעדכון הזה

### 1. כפתור פלוס צף (⊕)
בפינה השמאלית התחתונה, בכל מסך. לחיצה פותחת תפריט קטן עם 4 אפשרויות:
- + משימה
- + הנחייה
- + בקשה לפגישה
- + בקשה ללו״ז

הכפתורים הישנים בראש הדף הוסרו — הכל דרך הפלוס.

### 2. פגישות — לוגיקת אישור חדשה
- **מי שהזמין לא מאשר** — הוא לא מופיע כמי שצריך לאשר את הפגישה שלו.
- **קצינים לא מאשרים** — אם קצין הוזמן, הפגישה פשוט מופיעה אצלו, בלי checkbox אישור.
- **צוערים מוזמנים** — רואים checkbox "מאשר/ת הגעה" + תג סטטוס:
  - 🟠 **ממתין לאישור** — כל עוד לא כולם אישרו
  - 🟢 **מאושר** — כשכולם (הצוערים המוזמנים) אישרו
- **מחיקה** — כל מוזמן (לא רק המזמין) יכול למחוק את הפגישה.
- **עריכה** — כפתור "ערוך מועד" (למזמין ולקצינים) פותח חלון קטן לעריכת **תאריך ושעה בלבד**.

### 3. בקשה ללו״ז — טאב חדש
טופס עם: כותרת, סוג (יוזמה / התנסות / מסדר), משך זמן משוער (מספר + יחידה: דקות/שעות).
מוחק: היוצר או קצין.

## Collections ב-Firestore
`tasks`, `guides`, `meets`, `schedule`

וודאו שחוקי ה-Security Rules שלכם מאפשרים read/write לכל 4 ה-collections (לא רק tasks/guides/meets).
